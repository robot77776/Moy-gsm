МОЙ ГСМ — версия 1

Файлы:
- index.html — приложение
- manifest.json — параметры установки на экран iPhone
- sw.js — базовый офлайн-кеш

Размещение:
1. Создайте новый публичный репозиторий GitHub, например Moy-GSM.
2. Загрузите в корень все три файла.
3. В Settings → Pages выберите Deploy from a branch, ветку main и папку /(root).
4. Сохраните и дождитесь публикации.
5. Откройте опубликованный адрес в Safari на iPhone → Поделиться → На экран «Домой».

Важно:
- Данные хранятся локально в браузере на устройстве. Очистка данных Safari может их удалить.
- Не вводите смены на разных устройствах, если хотите общую историю: синхронизации пока нет.
- Нормы расхода пустые: заполните их в разделе «Автомобили».
- Прогрев пока не учитывается.

Фотографии автомобилей загружаются с внешних сайтов при наличии интернета. Можно заменить фотографию своей через настройки автомобиля.
